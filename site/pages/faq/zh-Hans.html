大家最先会问的问题

这些问题值得在下载之前而不是之后回答。

为什么需要管理员权限？

因为数据包是由内核驱动拦截的，而 Windows 不会为普通用户加载驱动。程序启动时会自行请求这些权限。在命令行下，它会以特定的退出码拒绝运行，而不是中途失败。

它会弄坏整台电脑，还是只影响我的应用？

取决于你把它指向什么。设置了目标，就只有那个应用受影响。目标留空，则电脑上的每个连接都会受影响，程序会在窗口和命令行中提醒你这一点，免得你纳闷视频通话为什么断了。

怎么撤销？

点击{{app.buttons.stop}}。关闭程序效果相同，设置了时间限制的话，到时也一样。如果工具本身在会话中途崩溃，其内部的看门狗会关闭捕获，而不是让你的网络一直处于受影响的状态，会话绝不能比启动它的程序存活得更久。

它会向任何地方发送数据吗？

不会。没有分析统计，没有向任何服务的崩溃上报，也没有更新检查。程序根本没有网络客户端。它唯一能发起的对外连接，是在你点击之后在浏览器中打开支持页面。它拦截的是你的流量，所以这些流量绝不能离开你的机器；你正在阅读的这个页面同样不会从别人那里加载任何东西。

Windows 对下载发出了警告，为什么？

程序已签名，所以警告里会显示签名者，而不是“未知发布者”。SmartScreen 仍可能警告一段时间，因为证书是新的，它还没有经常见到。一些杀毒软件也可能对请求管理员权限并加载网络驱动的程序作出反应。每个版本都会发布 SHA-256 校验和和一份带签名的组件清单，所以你可以验证自己下载的内容，而不是相信一个绿色的对勾。

我的下载彻底中断了，而且没有任何提示原因

检查最大数据包大小。设得足够低时，它就不是更小的数据包，而是一个黑洞：网络丢弃过大的数据包，而且从不报告。把它改回去，传输就会恢复。

它能在 Linux 或 macOS 上用吗？

不能，将来也不会。它建立在 Windows 内核驱动之上。在 Linux 上，tc 配合 netem 可以完成这项工作，而且系统已经自带。

它真的免费吗？可以在工作中使用吗？

是的。它是免费的开源软件，采用 GNU GPL v3 许可，包括在工作中使用，任何人都可以阅读或修改源码。所有人下载的都是同一个文件。
