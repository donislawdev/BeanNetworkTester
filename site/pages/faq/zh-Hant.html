大家最先會問的問題

這些問題值得在下載之前而不是之後回答。

為什麼需要管理員權限？

因為封包是由核心驅動程式攔截的，而 Windows 不會為普通使用者載入驅動程式。程式啟動時會自行請求這些權限。在命令列下，它會以特定的結束代碼拒絕執行，而不是中途失敗。

它會弄壞整台電腦，還是只影響我的應用？

取決於你把它指向什麼。設定了目標，就只有那個應用受影響。目標留空，則電腦上的每個連線都會受影響，程式會在視窗和命令列中提醒你這一點，免得你納悶視訊通話為什麼斷了。

怎麼復原？

點選{{app.buttons.stop}}。關閉程式效果相同，設定了時間限制的話，到時也一樣。如果工具本身在會話中途崩潰，其內部的看門狗會關閉擷取，而不是讓你的網路一直處於受影響的狀態，會話絕不能比啟動它的程式存活得更久。

它會向任何地方傳送資料嗎？

不會。沒有分析統計，沒有向任何服務的當機回報，也沒有更新檢查。程式根本沒有網路用戶端。它唯一能發起的對外連線，是在你點選之後在瀏覽器中開啟支援頁面。它攔截的是你的流量，所以這些流量絕不能離開你的機器；你正在閱讀的這個頁面同樣不會從別人那裡載入任何東西。

Windows 對下載發出了警告，為什麼？

程式已簽署，所以警告裡會顯示簽署者，而不是「不明的發行者」。SmartScreen 仍可能警告一段時間，因為憑證是新的，它還沒有經常見到。一些防毒軟體也可能對請求管理員權限並載入網路驅動程式的程式作出反應。每個版本都會發布 SHA-256 檢查碼和一份帶簽章的元件清單，所以你可以驗證自己下載的內容，而不是相信一個綠色的對勾。

我的下載徹底中斷了，而且沒有任何提示原因

檢查最大封包大小。設得足夠低時，它就不是更小的封包，而是一個黑洞：網路丟棄過大的封包，而且從不報告。把它改回去，傳輸就會恢復。

它能在 Linux 或 macOS 上用嗎？

不能，將來也不會。它建立在 Windows 核心驅動程式之上。在 Linux 上，tc 配合 netem 可以完成這項工作，而且系統已經自帶。

它真的免費嗎？可以在工作中使用嗎？

是的。它是免費的開源軟體，採用 GNU GPL v3 授權，包括在工作中使用，任何人都可以閱讀或修改原始碼。所有人下載的都是同一個檔案。
