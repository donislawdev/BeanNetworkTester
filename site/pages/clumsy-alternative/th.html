ทางเลือกแทน Clumsy บน Windows

Clumsy เป็นเครื่องมือที่คนส่วนใหญ่พบก่อน และเป็นเครื่องมือที่ดี ฟรี ใบอนุญาต MIT โต้ตอบได้ และสร้างบนไดรเวอร์ WinDivert ตัวเดียวกับที่เครื่องมือนี้ใช้ ถ้ามันทำสิ่งที่คุณต้องการได้ ก็ใช้มันเลย หน้านี้ว่าด้วยกรณีที่มันทำไม่ได้

สิ่งที่ควรดู ไม่ว่าจะเลือกตัวไหน

คำถามเหตุใดจึงตัดสินการเลือกเครื่องมือ
เจาะจงแอปเดียวได้หรือไม่ถ้าไม่ได้ คุณจะทำให้เครื่องที่ใช้งานอยู่แย่ลงทั้งเครื่อง รวมถึงเซสชันระยะไกลและเบราว์เซอร์ที่คุณใช้อ่านเอกสาร
มีบรรทัดคำสั่งหรือไม่ไปป์ไลน์คลิกช่องทำเครื่องหมายไม่ได้ ถ้าไม่มีบรรทัดคำสั่ง การทดสอบเครือข่ายก็ไม่มีวันเป็นส่วนหนึ่งของบิลด์
การรันทำซ้ำได้หรือไม่การสูญหายแบบสุ่มที่เล่นซ้ำไม่ได้ทำให้เกิดรายงานบั๊กที่คนอื่นทำซ้ำไม่ได้
หยุดเองหรือไม่เครื่องมือที่ต้องจำไปปิดเองจะถูกปล่อยให้เปิดค้างไว้
บอกได้หรือไม่ว่ามันทำอะไรลงไปจริง ๆตัวนับและรายการการเชื่อมต่อเปลี่ยน “รู้สึกว่าช้า” ให้เป็นตัวเลข

เครื่องมือนี้เพิ่มอะไร

  • เจาะจงตามโปรเซส PID ที่อยู่ หรือพอร์ต โดยตามต้นไม้โปรเซสไปด้วย เบราว์เซอร์ที่มีโปรเซสลูกสามสิบตัวจึงยังเป็นเป้าหมายเดียว
  • ไฟล์ปฏิบัติการเดียวกันคือบรรทัดคำสั่ง มีรหัสออกสำหรับทุกผลลัพธ์และเอาต์พุต NDJSON จึงใช้ใน CI ได้
  • การรันด้วย seed seed เดียวกันเล่นซ้ำการสูญหายแบบสุ่มและจิตเตอร์ชุดเดิม
  • โปรไฟล์สำเร็จรูป 3G, LTE, ดาวเทียม, คาเฟ่ที่แออัด, Wi-Fi บนเครื่องบิน, โมเด็ม 56k คุณจึงเริ่มจากสิ่งที่น่าเชื่อถือแทนการเดาตัวเลข
  • เซสชันจับเวลาและสถานการณ์จำลองแบบสคริปต์ ให้การทำให้เครือข่ายแย่เปลี่ยนเองขณะที่คุณดูแอป
  • มุมมองสด แผนภูมิ ตัวนับ และตารางการเชื่อมต่อที่แสดงว่าการเชื่อมต่อใดถูกกระทบ
  • อินเทอร์เฟซภาษาอังกฤษ โปแลนด์ และจีนตัวย่อ และไม่มีเทเลเมทรีใด ๆ

ถ้าคุณมาจากเครื่องมืออื่น

มีสี่ชื่อที่ผุดขึ้นมาเสมอเมื่อพูดถึงเรื่องนี้ และไม่ได้ใช้แทนกันได้

ที่คุณรู้จักคืออะไรสิ่งที่คาดหวังได้ที่นี่
tc กับ netemคำตอบของ Linux ที่ฝังอยู่ในเคอร์เนลและควบคุมจากบรรทัดคำสั่ง มักเป็นสิ่งที่การค้นหาการจำลอง WAN ส่งกลับมาบน Windows ไม่มี tc สิ่งนี้ใกล้เคียงที่สุดในเชิงแนวคิด คือการทำให้เครือข่ายแย่ในแบบเดียวกัน บรรทัดคำสั่งที่มีรหัสออก และไดรเวอร์แทนวินัยการจัดคิว
Clumsyเครื่องมือ Windows ฟรี ใบอนุญาต MIT โต้ตอบได้ บนไดรเวอร์ WinDivert ตัวเดียวกันเลือกมันเมื่อหน้าต่างกับตัวกรองก็พอแล้ว มาที่นี่เมื่อต้องการเจาะจงตามโปรเซส การรันด้วย seed และบรรทัดคำสั่งที่ไปป์ไลน์เรียกได้
NetLimiterผลิตภัณฑ์ Windows เชิงพาณิชย์สำหรับจัดการแบนด์วิดท์ต่อแอปอย่างถาวรเป็นงานคนละอย่าง ตัวนี้เป็นเครื่องมือทดสอบ เปิดช่วงหนึ่งแล้วปิด และทำให้แย่ได้มากกว่าความเร็วมาก
Fiddler หรือ Charlesพร็อกซีที่ตรวจสอบ เขียนทับ และเค้นทราฟฟิกที่ผ่านตัวมันได้ก็เป็นงานคนละอย่างเช่นกัน พร็อกซีกำหนดรูปร่างสิ่งที่มันพร็อกซีและเห็นข้อมูล ตัวนี้กำหนดรูปร่างการเชื่อมต่อเอง รวมถึง UDP และทุกอย่างที่ไม่เคยผ่านพร็อกซี

พูดตรง ๆ ถ้าคุณต้องการตัวจำลองเครือข่ายสำหรับแอป Windows แอปเดียวที่มีบรรทัดคำสั่ง นี่คือเครื่องมือประเภทที่คุณมองหา ถ้าต้องการอ่านและแก้ข้อมูลของแอป คุณต้องใช้พร็อกซี และถ้าอยู่บน Linux คุณมี netem อยู่แล้ว

เมื่อไรควรใช้อย่างอื่น

การพูดตามตรงเรื่องนี้ถูกกว่าการดาวน์โหลดที่ทำให้ผิดหวัง

  • คุณใช้ Linux หรือ macOS ตัวนี้ใช้ได้เฉพาะ Windows และจะเป็นเช่นนั้นตลอดไป เพราะสร้างบนไดรเวอร์ของ Windows บน Linux tc กับ netem คือคำตอบมาตรฐานและไม่ต้องใช้ซอฟต์แวร์เพิ่ม
  • คุณต้องการการจัดการแบนด์วิดท์ถาวร สำหรับทั้งเครื่อง แยกตามแอป เป็นฟีเจอร์ของผลิตภัณฑ์ ไม่ใช่การทดสอบ นั่นคือหน้าที่ของเครื่องมือจัดรูปทราฟฟิกเชิงพาณิชย์อย่าง NetLimiter ตัวนี้เป็นเครื่องมือทดสอบ ออกแบบให้เปิดช่วงหนึ่งแล้วปิด
  • คุณขอสิทธิ์ผู้ดูแลระบบไม่ได้ การดักจับแพ็กเก็ตต้องใช้สิทธิ์นั้น ไม่มีทางอ้อม และเครื่องมือที่อ้างว่ามีก็ไม่ได้ดักจับทราฟฟิกของคุณ
  • คุณต้องตรวจสอบและเขียนทับข้อมูลของแอป ไม่ใช่ทำให้ลิงก์แย่ลง นั่นเป็นงานของพร็อกซี
