Windows 版是一个无需安装就能运行的 zip 压缩包，或者面向电脑上所有用户的安装程序。无论哪种方式，程序都会自行请求管理员权限。Linux 版也有安装包，属于实验性支持。

关键信息一览

  • 价格：免费，并且是自由软件，采用 GNU GPL v3。
  • 运行环境：Windows 10 和 Windows 11，64 位。Linux（实验性支持）：64 位（x86_64），已在 Ubuntu 24.04 和 26.04 上验证。
  • 需要：管理员权限，因为流量由驱动程序捕获。在 Linux 上需要 root 权限和 5.10 或更新的内核。
  • 安装：无需安装。把 zip 解压到任意位置即可运行。也可以使用 .msi 安装程序，它会添加“开始”菜单项，并把程序加入 PATH（需要管理员权限）。在 Linux 上，解压 .tar.gz 即可。
  • 是否发送数据：不会自行发送。没有遥测，没有更新检查。{{app.tools.ping.tab}} 工具只向你输入的地址发送。
  • 模式：一个窗口，以及同一个文件作为命令行工具。
  • 源码：在 GitHub 上，采用相同的许可证。

发行包里有什么

每个版本会发布八个文件。其中三个是程序本身，另外五个则是为了让你不必盲目信任这份下载：

  • zip 压缩包：程序及其使用的驱动，放在同一个文件夹里；
  • .msi 安装程序：同一个程序，为电脑上所有用户安装，并带有“开始”菜单项；
  • .tar.gz：Linux 版程序，自带 Python，属于实验性支持；
  • SHA256SUMS.txt：zip 压缩包、安装程序和 Linux 安装包的校验和；
  • 两份 SBOM：标准格式的清单，列出内部的每个组件及其版本和许可证，一份针对 zip 压缩包签名，另一份针对 Linux 安装包签名；
  • 两个 .sigstore.json 文件：以文件形式保存的这些签名，无需询问 GitHub 就能校验。

确认你拿到的就是我们构建的文件

校验和回答的是“这个文件在传输中有没有被改动”。在 PowerShell 中，把输出与 SHA256SUMS.txt 里对应的那一行比较（对于安装程序，把 .zip 换成 .msi）：

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

签名回答的是另一个问题：“这个文件是不是出自那个仓库”，并且需要 GitHub 命令行工具：

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

在 Linux 上，在存放安装包和 SHA256SUMS.txt 的文件夹中运行这两项检查：

sha256sum -c --ignore-missing SHA256SUMS.txt
gh attestation verify BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

把你下载的文件的名称写在第一部分：gh 在这里不接受 *。请保留 --predicate-type：没有它，gh 会去找另一种声明，并报告说什么都没找到。

从下载所在的同一个页面复制来的校验和，证明力不如签名。两者都已发布，所以都值得花一点时间核对。

Windows 可能会发出警告

程序和安装程序都已签名，所以 Windows 会显示签名者，而不是“未知发布者”。证书是新的，所以 SmartScreen 可能仍会警告一段时间，因为它还没有经常见到这个证书。这涉及的是证书，而不是文件本身，上面的两种校验可以让你自己验证文件。常见问题页面对此以及驱动所需的条件有说明。

在 Linux 上

这个安装包就是同一个程序，自带 Python 和 Tk，因此不需要事先安装任何东西。解压，加入应用程序菜单，然后启动：

tar -xzf BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz
cd BeanNetworkTester
./BeanNetworkTester --install-desktop
./BeanNetworkTester

如果不用 sudo 启动，窗口会在桌面自带的对话框中请求管理员密码。安装包需要 glibc 2.38 或更新版本，因此 Ubuntu 22.04 和 Debian 12 太旧，无法运行。Linux 支持属于实验性质，与 Windows 的不同之处见 README。
