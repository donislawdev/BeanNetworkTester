关键信息一览

  • 价格：免费，并且是自由软件，采用 GNU GPL v3。
  • 运行环境：Windows 10 和 Windows 11，64 位。
  • 需要：管理员权限，因为流量由驱动程序捕获。
  • 安装：无需安装。把 zip 解压到任意位置即可运行。也可以使用 .msi 安装程序，它会添加“开始”菜单项，并把程序加入 PATH（需要管理员权限）。
  • 是否发送数据：不发送。没有遥测，没有更新检查，没有网络客户端。
  • 模式：一个窗口，以及同一个文件作为命令行工具。
  • 源码：在 GitHub 上，采用相同的许可证。

发行包里有什么

每个版本会发布五个文件。其中两个是程序本身，另外三个则是为了让你不必盲目信任这份下载：

  • zip 压缩包：程序及其使用的驱动，放在同一个文件夹里；
  • .msi 安装程序：同一个程序，为电脑上所有用户安装，并带有“开始”菜单项；
  • SHA256SUMS.txt：zip 压缩包和安装程序的校验和；
  • SBOM：一份标准格式的清单，列出内部的每个组件及其版本和许可证，并针对 zip 压缩包签名；
  • .sigstore.json 文件：以文件形式保存的该签名，无需询问 GitHub 就能校验。

确认你拿到的就是我们构建的文件

校验和回答的是“这个文件在传输中有没有被改动”。在 PowerShell 中，把输出与 SHA256SUMS.txt 里对应的那一行比较（对于安装程序，把 .zip 换成 .msi）：

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

签名回答的是另一个问题：“这个文件是不是出自那个仓库”，并且需要 GitHub 命令行工具：

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

把你下载的 zip 文件的名称写在第一部分：gh 在这里不接受 *。请保留 --predicate-type：没有它，gh 会去找另一种声明，并报告说什么都没找到。

从下载所在的同一个页面复制来的校验和，证明力不如签名。两者都已发布，所以都值得花一点时间核对。

Windows 可能会发出警告

程序和安装程序都已签名，所以 Windows 会显示签名者，而不是“未知发布者”。证书是新的，所以 SmartScreen 可能仍会警告一段时间，因为它还没有经常见到这个证书。这涉及的是证书，而不是文件本身，上面的两种校验可以让你自己验证文件。常见问题页面对此以及驱动所需的条件有说明。
