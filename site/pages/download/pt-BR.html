Baixar o Bean Network Tester

Para Windows, um zip que roda sem instalar nada, ou um instalador para todos os usuários do computador. De qualquer forma, o programa pede permissões de administrador sozinho. Para Linux também há um pacote, de forma experimental.

{{cta.download}}

Os fatos em um só lugar

  • Preço: grátis, e software livre: GNU GPL v3.
  • Roda em: Windows 10 e Windows 11, 64 bits. Linux, de forma experimental: 64 bits (x86_64), testado no Ubuntu 24.04 e 26.04.
  • Precisa de: permissões de administrador, porque o tráfego é capturado por um driver. No Linux, permissões de root e kernel 5.10 ou mais novo.
  • Instalação: desnecessária. Descompacte o zip em qualquer lugar e execute. Ou use o instalador .msi, que adiciona uma entrada ao menu Iniciar e coloca o programa no PATH (precisa de permissões de administrador). No Linux, descompacte o .tar.gz.
  • Envia dados: nada por conta própria. Sem telemetria, sem verificação de atualizações. A ferramenta {{app.tools.ping.tab}} só envia para o endereço que você digita.
  • Modos: uma janela e o mesmo arquivo como ferramenta de linha de comando.
  • Código-fonte: no GitHub, sob a mesma licença.

O que vem na versão

Uma versão publica oito arquivos. Três são o programa, e os outros cinco existem para que você não precise confiar cegamente no download:

  • o zip: o programa e o driver que ele usa, juntos em uma pasta;
  • o instalador .msi: o mesmo programa, instalado para todos os usuários do computador, com uma entrada no menu Iniciar;
  • o .tar.gz: o programa para Linux, com o próprio Python, de forma experimental;
  • SHA256SUMS.txt: as somas de verificação do zip, do instalador e do pacote para Linux;
  • dois SBOMs: listas padrão de todos os componentes internos, com versões e licenças, uma assinada em relação ao zip e outra em relação ao pacote para Linux;
  • dois arquivos .sigstore.json: essas assinaturas como arquivos, para conferir sem perguntar ao GitHub.

Conferir se você recebeu o que construímos

A soma de verificação responde “isto chegou sem alterações”. No PowerShell, compare a saída com a linha em SHA256SUMS.txt (para o instalador, use .msi no lugar de .zip):

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

A assinatura responde a outra pergunta, “isto saiu daquele repositório”, e precisa da ferramenta de linha de comando do GitHub:

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

No Linux, rode as duas verificações na pasta onde estão o pacote e o SHA256SUMS.txt:

sha256sum -c --ignore-missing SHA256SUMS.txt
gh attestation verify BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Digite como primeira parte o nome do arquivo que você baixou: o gh não aceita um * ali. Mantenha --predicate-type: sem ele, o gh procura outro tipo de declaração e informa que não encontrou nenhuma.

Uma soma de verificação copiada da mesma página do download prova menos que uma assinatura. As duas são publicadas, então as duas valem um momento.

O Windows pode avisar você

O programa e o instalador são assinados, então o Windows mostra quem os assinou em vez de dizer “Editor desconhecido”. O certificado é novo, então o SmartScreen ainda pode avisar por um tempo, porque ainda não o viu muitas vezes. Isso é sobre o certificado, não sobre o arquivo, e as duas verificações acima deixam você conferir o arquivo por conta própria. A página de perguntas trata disso e do que o driver precisa.

No Linux

O pacote é o mesmo programa com o próprio Python e Tk, então não é preciso instalar nada antes. Descompacte, adicione ao menu de aplicativos e abra:

tar -xzf BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz
cd BeanNetworkTester
./BeanNetworkTester --install-desktop
./BeanNetworkTester

Aberta sem sudo, a janela pede a senha de um administrador no diálogo do próprio desktop. O pacote precisa de glibc 2.38 ou mais novo, então o Ubuntu 22.04 e o Debian 12 são antigos demais para ele. O suporte a Linux é um experimento, e o README explica onde ele difere do Windows.
