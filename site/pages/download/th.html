ข้อเท็จจริงในที่เดียว

  • ราคา: ฟรี และเป็นซอฟต์แวร์เสรี GNU GPL v3
  • รันบน: Windows 10 และ Windows 11 แบบ 64 บิต
  • ต้องมี: สิทธิ์ผู้ดูแลระบบ เพราะไดรเวอร์เป็นตัวดักจับทราฟฟิก
  • การติดตั้ง: ไม่จำเป็น แตก zip ที่ไหนก็ได้แล้วรัน หรือใช้ตัวติดตั้ง .msi ซึ่งเพิ่มรายการในเมนูเริ่มและวางโปรแกรมไว้ใน PATH (ต้องใช้สิทธิ์ผู้ดูแลระบบ)
  • ส่งข้อมูลหรือไม่: ไม่ส่งไปที่ใด ไม่มีเทเลเมทรี ไม่มีการตรวจสอบอัปเดต ไม่มีไคลเอนต์เครือข่าย
  • โหมด: หน้าต่าง และไฟล์เดียวกันใช้เป็นเครื่องมือบรรทัดคำสั่ง
  • ซอร์ส: บน GitHub ภายใต้ใบอนุญาตเดียวกัน

สิ่งที่อยู่ในรุ่นที่ปล่อย

แต่ละรุ่นเผยแพร่ห้าไฟล์ สองไฟล์เป็นตัวโปรแกรม และอีกสามไฟล์มีไว้เพื่อให้คุณไม่ต้องเชื่อการดาวน์โหลดแบบไม่มีหลักฐาน:

  • ไฟล์ zip โปรแกรมและไดรเวอร์ที่ใช้ รวมอยู่ในโฟลเดอร์เดียว
  • ตัวติดตั้ง .msi โปรแกรมเดียวกัน ติดตั้งให้ผู้ใช้ทุกคนบนคอมพิวเตอร์ พร้อมรายการในเมนูเริ่ม
  • SHA256SUMS.txt เช็กซัมของไฟล์ zip และตัวติดตั้ง
  • SBOM รายการมาตรฐานของทุกองค์ประกอบภายใน พร้อมเวอร์ชันและใบอนุญาต ลงนามไว้กับไฟล์ zip
  • ไฟล์ .sigstore.json ลายเซ็นนั้นในรูปแบบไฟล์ เพื่อตรวจสอบได้โดยไม่ต้องถาม GitHub

ตรวจว่าคุณได้สิ่งที่เราสร้าง

เช็กซัมตอบคำถามว่า “มาถึงโดยไม่ถูกเปลี่ยนหรือไม่” ใน PowerShell ให้เทียบผลลัพธ์กับบรรทัดใน SHA256SUMS.txt (สำหรับตัวติดตั้ง ให้ใช้ .msi แทน .zip):

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

ลายเซ็นตอบคำถามอีกข้อ “สิ่งนี้มาจากรีโพซิทอรีนั้นหรือไม่” และต้องใช้เครื่องมือบรรทัดคำสั่งของ GitHub:

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

พิมพ์ชื่อไฟล์ zip ที่คุณดาวน์โหลดเป็นส่วนแรก gh ไม่ยอมรับ * ตรงนั้น คง --predicate-type ไว้ ถ้าไม่มี gh จะหาข้อความรับรองอีกชนิดและรายงานว่าไม่พบ

เช็กซัมที่คัดลอกจากหน้าเดียวกับการดาวน์โหลดพิสูจน์ได้น้อยกว่าลายเซ็น ทั้งสองอย่างเผยแพร่ไว้ จึงควรตรวจทั้งคู่

Windows อาจเตือนคุณ

โปรแกรมและตัวติดตั้งลงนามไว้แล้ว Windows จึงแสดงชื่อผู้ลงนามแทนคำว่า “ผู้เผยแพร่ที่ไม่รู้จัก” ใบรับรองเป็นของใหม่ SmartScreen จึงอาจยังเตือนอยู่พักหนึ่ง เพราะยังไม่เห็นมันบ่อยนัก เรื่องนี้เกี่ยวกับใบรับรอง ไม่ใช่ไฟล์ และการตรวจสองอย่างข้างต้นให้คุณตรวจไฟล์ด้วยตัวเองได้ หน้าคำถาม กล่าวถึงเรื่องนี้และสิ่งที่ไดรเวอร์ต้องการ
