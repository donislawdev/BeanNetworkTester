ดาวน์โหลด Bean Network Tester

สำหรับ Windows มีไฟล์ zip ที่รันได้โดยไม่ต้องติดตั้ง หรือตัวติดตั้งสำหรับผู้ใช้ทุกคนบนคอมพิวเตอร์ ไม่ว่าแบบไหน โปรแกรมจะขอสิทธิ์ผู้ดูแลระบบเอง สำหรับ Linux ก็มีแพ็กเกจด้วย ในแบบทดลอง

ข้อเท็จจริงในที่เดียว

  • ราคา: ฟรี และเป็นซอฟต์แวร์เสรี GNU GPL v3
  • รันบน: Windows 10 และ Windows 11 แบบ 64 บิต Linux ในแบบทดลอง: 64 บิต (x86_64) ตรวจแล้วบน Ubuntu 24.04 และ 26.04
  • ต้องมี: สิทธิ์ผู้ดูแลระบบ เพราะไดรเวอร์เป็นตัวดักจับทราฟฟิก บน Linux ต้องมีสิทธิ์ root และเคอร์เนล 5.10 ขึ้นไป
  • การติดตั้ง: ไม่จำเป็น แตก zip ที่ไหนก็ได้แล้วรัน หรือใช้ตัวติดตั้ง .msi ซึ่งเพิ่มรายการในเมนูเริ่มและวางโปรแกรมไว้ใน PATH (ต้องใช้สิทธิ์ผู้ดูแลระบบ) บน Linux ให้แตกไฟล์ .tar.gz
  • ส่งข้อมูลหรือไม่: ไม่ส่งสิ่งใดออกไปเอง ไม่มีเทเลเมทรี ไม่มีการตรวจสอบอัปเดต เครื่องมือ {{app.tools.ping.tab}} ส่งไปยังที่อยู่ที่คุณพิมพ์เท่านั้น
  • โหมด: หน้าต่าง และไฟล์เดียวกันใช้เป็นเครื่องมือบรรทัดคำสั่ง
  • ซอร์ส: บน GitHub ภายใต้ใบอนุญาตเดียวกัน

สิ่งที่อยู่ในรุ่นที่ปล่อย

แต่ละรุ่นเผยแพร่แปดไฟล์ สามไฟล์เป็นตัวโปรแกรม และอีกห้าไฟล์มีไว้เพื่อให้คุณไม่ต้องเชื่อการดาวน์โหลดแบบไม่มีหลักฐาน:

  • ไฟล์ zip โปรแกรมและไดรเวอร์ที่ใช้ รวมอยู่ในโฟลเดอร์เดียว
  • ตัวติดตั้ง .msi โปรแกรมเดียวกัน ติดตั้งให้ผู้ใช้ทุกคนบนคอมพิวเตอร์ พร้อมรายการในเมนูเริ่ม
  • ไฟล์ .tar.gz โปรแกรมสำหรับ Linux พร้อม Python ของตัวเอง ในแบบทดลอง
  • SHA256SUMS.txt เช็กซัมของไฟล์ zip ตัวติดตั้ง และแพ็กเกจ Linux
  • SBOM สองชุด รายการมาตรฐานของทุกองค์ประกอบภายใน พร้อมเวอร์ชันและใบอนุญาต ชุดหนึ่งลงนามไว้กับไฟล์ zip อีกชุดกับแพ็กเกจ Linux
  • ไฟล์ .sigstore.json สองไฟล์ ลายเซ็นเหล่านั้นในรูปแบบไฟล์ เพื่อตรวจสอบได้โดยไม่ต้องถาม GitHub

ตรวจว่าคุณได้สิ่งที่เราสร้าง

เช็กซัมตอบคำถามว่า “มาถึงโดยไม่ถูกเปลี่ยนหรือไม่” ใน PowerShell ให้เทียบผลลัพธ์กับบรรทัดใน SHA256SUMS.txt (สำหรับตัวติดตั้ง ให้ใช้ .msi แทน .zip):

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

ลายเซ็นตอบคำถามอีกข้อ “สิ่งนี้มาจากรีโพซิทอรีนั้นหรือไม่” และต้องใช้เครื่องมือบรรทัดคำสั่งของ GitHub:

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

บน Linux ให้รันการตรวจทั้งสองในโฟลเดอร์ที่มีแพ็กเกจและ SHA256SUMS.txt:

sha256sum -c --ignore-missing SHA256SUMS.txt
gh attestation verify BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

พิมพ์ชื่อไฟล์ที่คุณดาวน์โหลดเป็นส่วนแรก gh ไม่ยอมรับ * ตรงนั้น คง --predicate-type ไว้ ถ้าไม่มี gh จะหาข้อความรับรองอีกชนิดและรายงานว่าไม่พบ

เช็กซัมที่คัดลอกจากหน้าเดียวกับการดาวน์โหลดพิสูจน์ได้น้อยกว่าลายเซ็น ทั้งสองอย่างเผยแพร่ไว้ จึงควรตรวจทั้งคู่

Windows อาจเตือนคุณ

โปรแกรมและตัวติดตั้งลงนามไว้แล้ว Windows จึงแสดงชื่อผู้ลงนามแทนคำว่า “ผู้เผยแพร่ที่ไม่รู้จัก” ใบรับรองเป็นของใหม่ SmartScreen จึงอาจยังเตือนอยู่พักหนึ่ง เพราะยังไม่เห็นมันบ่อยนัก เรื่องนี้เกี่ยวกับใบรับรอง ไม่ใช่ไฟล์ และการตรวจสองอย่างข้างต้นให้คุณตรวจไฟล์ด้วยตัวเองได้ หน้าคำถาม กล่าวถึงเรื่องนี้และสิ่งที่ไดรเวอร์ต้องการ

บน Linux

แพ็กเกจนี้คือโปรแกรมเดียวกัน พร้อม Python และ Tk ของตัวเอง จึงไม่ต้องติดตั้งอะไรก่อน แตกไฟล์ เพิ่มลงในเมนูแอปพลิเคชัน แล้วเปิดใช้:

tar -xzf BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz
cd BeanNetworkTester
./BeanNetworkTester --install-desktop
./BeanNetworkTester

เมื่อเปิดโดยไม่ใช้ sudo หน้าต่างจะขอรหัสผ่านผู้ดูแลระบบผ่านกล่องโต้ตอบของเดสก์ท็อปเอง แพ็กเกจต้องใช้ glibc 2.38 ขึ้นไป Ubuntu 22.04 และ Debian 12 จึงเก่าเกินไป การรองรับ Linux ยังเป็นแบบทดลอง และ README บอกว่าต่างจาก Windows ตรงไหน
