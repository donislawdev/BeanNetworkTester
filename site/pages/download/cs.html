Stáhnout Bean Network Tester

Pro Windows zip, který běží bez instalace, nebo instalátor pro všechny uživatele počítače. V obou případech si program práva správce vyžádá sám. Pro Linux je k dispozici i balíček, jako experiment.

{{cta.download}}

Fakta na jednom místě

  • Cena: zdarma a svobodný software, GNU GPL v3.
  • Běží na: Windows 10 a Windows 11, 64 bitů. Linux jako experiment: 64 bitů (x86_64), ověřeno na Ubuntu 24.04 a 26.04.
  • Potřebuje: práva správce, protože provoz zachytává ovladač. Na Linuxu práva roota a jádro 5.10 nebo novější.
  • Instalace: není potřeba. Rozbalte zip kdekoli a spusťte. Nebo použijte instalátor .msi, který přidá položku do nabídky Start a dá program na PATH (vyžaduje práva správce). Na Linuxu rozbalte .tar.gz.
  • Odesílá data: sám od sebe nic. Žádná telemetrie, žádná kontrola aktualizací. Jeho nástroj {{app.tools.ping.tab}} posílá jen na adresu, kterou zadáte.
  • Režimy: okno a tentýž soubor jako nástroj příkazového řádku.
  • Zdroj: na GitHubu, pod stejnou licencí.

Co je ve vydání

Vydání zveřejňuje osm souborů. Tři jsou program a dalších pět tu je proto, abyste nemuseli stažení brát na slepou víru:

  • zip: program a ovladač, který používá, pohromadě v jedné složce;
  • instalátor .msi: tentýž program nainstalovaný pro všechny uživatele počítače, s položkou v nabídce Start;
  • .tar.gz: program pro Linux s vlastním Pythonem, jako experiment;
  • SHA256SUMS.txt: kontrolní součty zipu, instalátoru a balíčku pro Linux;
  • dva SBOM: standardní seznamy všech součástí uvnitř, s verzemi a licencemi, jeden podepsaný proti zipu a druhý proti balíčku pro Linux;
  • dva soubory .sigstore.json: tytéž podpisy jako soubory, aby šly ověřit bez dotazu na GitHub.

Ověření, že jste dostali, co jsme sestavili

Kontrolní součet odpovídá na otázku „dorazilo to beze změny“. V PowerShellu porovnejte výstup s řádkem v SHA256SUMS.txt (u instalátoru dosaďte .msi místo .zip):

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

Podpis odpovídá na jinou otázku, „vzniklo to v tom repozitáři“, a potřebuje nástroj příkazového řádku GitHubu:

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Na Linuxu spusťte obě kontroly ve složce, kde leží balíček a SHA256SUMS.txt:

sha256sum -c --ignore-missing SHA256SUMS.txt
gh attestation verify BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Jako první část zadejte název staženého souboru, protože gh tam * nepřijímá. Ponechte --predicate-type: bez něj gh hledá jiný druh prohlášení a oznámí, že žádné nenašel.

Kontrolní součet, který zkopírujete ze stejné stránky jako stažení, dokazuje méně než podpis. Zveřejněno je obojí, takže stojí za chvilku obojí.

Windows vás může varovat

Program i instalátor jsou podepsané, takže Windows uvede, kdo je podepsal, místo „Neznámý vydavatel“. Certifikát je nový, takže SmartScreen může ještě nějakou dobu varovat, protože ho zatím neviděl často. Jde o certifikát, ne o soubor, a obě výše uvedené kontroly vám umožní soubor ověřit samotným. Na stránce otázek je to popsáno i s tím, co ovladač potřebuje.

Na Linuxu

Balíček je tentýž program s vlastním Pythonem a Tk, takže předem není nutné nic instalovat. Rozbalte ho, přidejte do nabídky aplikací a spusťte:

tar -xzf BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz
cd BeanNetworkTester
./BeanNetworkTester --install-desktop
./BeanNetworkTester

Okno spuštěné bez sudo si řekne o heslo správce v dialogu pracovního prostředí. Balíček potřebuje glibc 2.38 nebo novější, takže Ubuntu 22.04 a Debian 12 jsou pro něj příliš staré. Podpora Linuxu je experiment a README popisuje, čím se liší od Windows.
