Télécharger Bean Network Tester

Pour Windows, un zip qui fonctionne sans rien installer, ou un installeur pour tous les utilisateurs de l’ordinateur. Dans les deux cas, le programme demande lui-même les droits d’administrateur. Pour Linux, il existe aussi un paquet, à titre expérimental.

{{cta.download}}

Les faits, au même endroit

  • Prix : gratuit, et logiciel libre, GNU GPL v3.
  • Fonctionne sur : Windows 10 et Windows 11, 64 bits. Linux, à titre expérimental : 64 bits (x86_64), vérifié sur Ubuntu 24.04 et 26.04.
  • Nécessite : des droits d’administrateur, car le trafic est capturé par un pilote. Sous Linux, les droits root et un noyau 5.10 ou plus récent.
  • Installation : inutile. Décompressez le zip où vous voulez et lancez-le. Ou utilisez l’installeur .msi, qui ajoute une entrée dans le menu Démarrer et place le programme dans le PATH (il demande des droits d’administrateur). Sous Linux, décompressez le .tar.gz.
  • Envoie des données : rien de lui-même. Pas de télémétrie, pas de vérification de mises à jour. Son outil {{app.tools.ping.tab}} n’envoie qu’à l’adresse que vous saisissez.
  • Modes : une fenêtre, et le même fichier comme outil en ligne de commande.
  • Source : sur GitHub, sous la même licence.

Ce que contient une version

Une version publie huit fichiers. Trois sont le programme, et les cinq autres sont là pour que vous n’ayez pas à croire le téléchargement sur parole :

  • le zip : le programme et le pilote qu’il utilise, réunis dans un seul dossier ;
  • l’installeur .msi : le même programme, installé pour tous les utilisateurs de l’ordinateur, avec une entrée dans le menu Démarrer ;
  • le .tar.gz : le programme pour Linux, avec son propre Python, à titre expérimental ;
  • SHA256SUMS.txt : les sommes de contrôle du zip, de l’installeur et du paquet Linux ;
  • deux SBOM : des listes standard de chaque composant embarqué, avec versions et licences, l’une signée par rapport au zip et l’autre par rapport au paquet Linux ;
  • deux fichiers .sigstore.json : ces signatures sous forme de fichiers, pour les vérifier sans interroger GitHub.

Vérifier que vous avez reçu ce que nous avons construit

La somme de contrôle répond à « est-ce arrivé inchangé ». Dans PowerShell, comparez la sortie avec la ligne de SHA256SUMS.txt (pour l’installeur, mettez .msi à la place de .zip) :

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

La signature répond à une autre question, « est-ce sorti de ce dépôt », et nécessite l’outil en ligne de commande de GitHub :

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Sous Linux, lancez les deux vérifications dans le dossier qui contient le paquet et SHA256SUMS.txt :

sha256sum -c --ignore-missing SHA256SUMS.txt
gh attestation verify BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Tapez le nom du fichier que vous avez téléchargé comme première partie : gh n’accepte pas de * à cet endroit. Gardez --predicate-type : sans lui, gh cherche un autre type de déclaration et signale qu’il n’en a trouvé aucune.

Une somme de contrôle que vous copiez depuis la même page que le téléchargement prouve moins qu’une signature. Les deux sont publiées, donc les deux méritent un instant.

Windows peut vous avertir

Le programme et l’installeur sont signés, si bien que Windows indique qui les a signés au lieu d’afficher « Éditeur inconnu ». Le certificat est récent, donc SmartScreen peut encore avertir un certain temps, car il ne l’a pas souvent rencontré. Cela concerne le certificat, pas le fichier, et les deux vérifications ci-dessus vous permettent de contrôler le fichier vous-même. La page de questions traite de cela et de ce dont le pilote a besoin.

Sous Linux

Le paquet est le même programme avec son propre Python et Tk, il n’y a donc rien à installer avant. Décompressez-le, ajoutez-le au menu des applications et lancez-le :

tar -xzf BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz
cd BeanNetworkTester
./BeanNetworkTester --install-desktop
./BeanNetworkTester

Lancée sans sudo, la fenêtre demande le mot de passe d’un administrateur dans la boîte de dialogue du bureau. Le paquet demande glibc 2.38 ou plus récent, donc Ubuntu 22.04 et Debian 12 sont trop anciens pour lui. La prise en charge de Linux est une expérience, et le README indique en quoi elle diffère de Windows.
