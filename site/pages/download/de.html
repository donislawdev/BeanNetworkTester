Bean Network Tester herunterladen

Für Windows ein Zip, das ohne Installation läuft, oder ein Installer für alle Nutzer des Rechners. In beiden Fällen fragt das Programm selbst nach Administratorrechten. Für Linux gibt es auch ein Paket, als Experiment.

{{cta.download}}

Die Fakten an einem Ort

  • Preis: kostenlos und freie Software, GNU GPL v3.
  • Läuft unter: Windows 10 und Windows 11, 64 Bit. Linux, als Experiment: 64 Bit (x86_64), geprüft unter Ubuntu 24.04 und 26.04.
  • Braucht: Administratorrechte, weil der Datenverkehr von einem Treiber erfasst wird. Unter Linux Root-Rechte und Kernel 5.10 oder neuer.
  • Installation: nicht nötig. Entpacke das Zip irgendwo und starte es. Oder nutze den .msi-Installer, der einen Startmenü-Eintrag anlegt und das Programm in den PATH aufnimmt (dafür sind Administratorrechte nötig). Unter Linux entpackst du das .tar.gz.
  • Sendet Daten: nichts von sich aus. Keine Telemetrie, keine Update-Prüfung. Sein Werkzeug {{app.tools.ping.tab}} sendet nur an die Adresse, die du eingibst.
  • Modi: ein Fenster und dieselbe Datei als Befehlszeilenprogramm.
  • Quellcode: auf GitHub, unter derselben Lizenz.

Was im Release steckt

Ein Release veröffentlicht acht Dateien. Drei davon sind das Programm, die anderen fünf sind dafür da, dass du den Download nicht einfach glauben musst:

  • das Zip: das Programm und der Treiber, den es nutzt, zusammen in einem Ordner;
  • der .msi-Installer: dasselbe Programm, für alle Nutzer des Rechners installiert, mit einem Startmenü-Eintrag;
  • das .tar.gz: das Programm für Linux, mit eigenem Python, als Experiment;
  • SHA256SUMS.txt: die Prüfsummen von Zip, Installer und Linux-Paket;
  • zwei SBOMs: Standardlisten aller enthaltenen Komponenten mit Versionen und Lizenzen, eine signiert gegen das Zip und eine gegen das Linux-Paket;
  • zwei .sigstore.json-Dateien: diese Signaturen als Dateien, um sie zu prüfen, ohne GitHub zu fragen.

Prüfen, ob du bekommen hast, was wir gebaut haben

Die Prüfsumme beantwortet „ist das unverändert angekommen“. Vergleiche in PowerShell die Ausgabe mit der Zeile in SHA256SUMS.txt (für den Installer setzt du .msi an die Stelle von .zip):

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

Die Signatur beantwortet eine andere Frage, nämlich „stammt das aus diesem Repository“, und braucht das GitHub-Befehlszeilenwerkzeug:

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Unter Linux führst du beide Prüfungen in dem Ordner aus, in dem das Paket und SHA256SUMS.txt liegen:

sha256sum -c --ignore-missing SHA256SUMS.txt
gh attestation verify BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Gib als ersten Teil den Namen der heruntergeladenen Datei ein: gh akzeptiert dort kein *. Lass --predicate-type stehen: Ohne es sucht gh nach einer anderen Art von Aussage und meldet, nichts gefunden zu haben.

Eine Prüfsumme, die du von derselben Seite wie den Download kopierst, beweist weniger als eine Signatur. Beides ist veröffentlicht, also lohnt sich beides.

Windows warnt dich vielleicht

Das Programm und der Installer sind signiert, sodass Windows nennt, wer sie signiert hat, statt „Unbekannter Herausgeber“ zu sagen. Das Zertifikat ist neu, deshalb warnt SmartScreen möglicherweise noch eine Weile, weil es es noch nicht oft gesehen hat. Das betrifft das Zertifikat, nicht die Datei, und mit den beiden Prüfungen oben kannst du die Datei selbst verifizieren. Die Fragenseite behandelt das und das, was der Treiber braucht.

Unter Linux

Das Paket ist dasselbe Programm mit eigenem Python und Tk, also muss vorher nichts installiert werden. Entpacke es, trage es ins Anwendungsmenü ein und starte es:

tar -xzf BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz
cd BeanNetworkTester
./BeanNetworkTester --install-desktop
./BeanNetworkTester

Ohne sudo gestartet, fragt das Fenster im Dialog des Desktops nach dem Passwort eines Administrators. Das Paket braucht glibc 2.38 oder neuer, daher sind Ubuntu 22.04 und Debian 12 dafür zu alt. Die Linux-Unterstützung ist ein Experiment, und die README sagt, wo sie sich von Windows unterscheidet.
