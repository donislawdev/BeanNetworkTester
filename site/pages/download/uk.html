Завантажити Bean Network Tester

Для Windows: zip, що працює без встановлення, або інсталятор для всіх користувачів комп’ютера. Так чи так програма сама просить права адміністратора. Для Linux є також пакет, експериментально.

{{cta.download}}

Факти в одному місці

  • Ціна: безкоштовно, і це вільне програмне забезпечення, GNU GPL v3.
  • Працює на: Windows 10 і Windows 11, 64-розрядна. Linux експериментально: 64-розрядний (x86_64), перевірено на Ubuntu 24.04 і 26.04.
  • Потребує: прав адміністратора, бо трафік перехоплює драйвер. У Linux прав root і ядра 5.10 або новішого.
  • Встановлення: не потрібне. Розпакуйте zip будь-куди й запускайте. Або скористайтеся інсталятором .msi, який додає пункт у меню «Пуск» і кладе програму в PATH (потрібні права адміністратора). У Linux розпакуйте .tar.gz.
  • Надсилає дані: нічого сама по собі. Жодної телеметрії чи перевірки оновлень. Інструмент {{app.tools.ping.tab}} надсилає лише на адресу, яку ви вводите.
  • Режими: вікно й той самий файл як інструмент командного рядка.
  • Вихідний код: на GitHub, за тією самою ліцензією.

Що входить до випуску

Випуск публікує вісім файлів. Три з них становлять програму, а решта п’ять є для того, щоб вам не довелося довіряти завантаженню на слово:

  • zip: програма й драйвер, який вона використовує, разом в одній теці;
  • інсталятор .msi: та сама програма, встановлена для всіх користувачів комп’ютера, із пунктом у меню «Пуск»;
  • .tar.gz: програма для Linux із власним Python, експериментально;
  • SHA256SUMS.txt: контрольні суми zip, інсталятора та пакета для Linux;
  • два SBOM: стандартні переліки всіх компонентів усередині з версіями та ліцензіями, один підписаний щодо zip, другий щодо пакета для Linux;
  • два файли .sigstore.json: ці підписи як файли, щоб перевірити їх, не питаючи GitHub.

Перевірка, що ви отримали те, що ми зібрали

Контрольна сума відповідає на питання «чи дійшло без змін». У PowerShell порівняйте вивід із рядком у SHA256SUMS.txt (для інсталятора підставте .msi замість .zip):

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

Підпис відповідає на інше питання, «чи це вийшло з того репозиторію», і потребує інструмента командного рядка GitHub:

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

У Linux запустіть обидві перевірки в теці, де лежать пакет і SHA256SUMS.txt:

sha256sum -c --ignore-missing SHA256SUMS.txt
gh attestation verify BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Як першу частину введіть назву завантаженого файлу: gh не приймає там *. Залиште --predicate-type: без нього gh шукає інший вид тверджень і повідомляє, що нічого не знайшов.

Контрольна сума, скопійована з тієї самої сторінки, що й завантаження, доводить менше, ніж підпис. Обидва опубліковані, тож обидва варто перевірити.

Windows може попередити

Програма та інсталятор підписані, тож Windows називає, хто їх підписав, замість «Невідомий видавець». Сертифікат новий, тому SmartScreen ще якийсь час може попереджати, бо він ще не бачив його часто. Це про сертифікат, а не про файл, і дві перевірки вище дають змогу перевірити файл самостійно. Сторінка запитань розповідає про це й про те, що потрібно драйверу.

У Linux

Пакет є тією самою програмою з власним Python і Tk, тож заздалегідь нічого встановлювати не треба. Розпакуйте його, додайте до меню застосунків і запустіть:

tar -xzf BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz
cd BeanNetworkTester
./BeanNetworkTester --install-desktop
./BeanNetworkTester

Запущене без sudo вікно просить пароль адміністратора в діалозі робочого столу. Пакету потрібна glibc 2.38 або новіша, тому Ubuntu 22.04 і Debian 12 для нього застарі. Підтримка Linux є експериментом, а README описує, чим вона відрізняється від Windows.
