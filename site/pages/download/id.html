Unduh Bean Network Tester

Zip yang berjalan tanpa menginstal apa pun, atau installer untuk semua pengguna di komputer. Apa pun pilihannya, program meminta hak administrator sendiri.

{{cta.download}}

Fakta-fakta di satu tempat

  • Harga: gratis, dan perangkat lunak bebas: GNU GPL v3.
  • Berjalan di: Windows 10 dan Windows 11, 64-bit.
  • Membutuhkan: hak administrator, karena lalu lintas ditangkap oleh driver.
  • Instalasi: tidak perlu. Ekstrak zip di mana saja lalu jalankan. Atau gunakan installer .msi, yang menambahkan entri Start Menu dan menaruh program di PATH (membutuhkan hak administrator).
  • Mengirim data: ke mana pun tidak. Tanpa telemetri, tanpa pengecekan pembaruan, tanpa klien jaringan.
  • Mode: sebuah jendela, dan file yang sama sebagai alat baris perintah.
  • Kode sumber: di GitHub, dengan lisensi yang sama.

Isi rilis

Satu rilis menerbitkan lima file. Dua adalah programnya, dan tiga lainnya ada agar Anda tidak perlu memercayai unduhan begitu saja:

  • zip: program dan driver yang dipakainya, bersama dalam satu folder;
  • installer .msi: program yang sama, dipasang untuk semua pengguna di komputer, dengan entri Start Menu;
  • SHA256SUMS.txt: checksum zip dan installer;
  • sebuah SBOM: daftar standar setiap komponen di dalamnya, dengan versi dan lisensi, ditandatangani terhadap zip;
  • file .sigstore.json: tanda tangan itu sebagai file, untuk memeriksanya tanpa bertanya ke GitHub.

Memastikan Anda menerima apa yang kami bangun

Checksum menjawab “apakah ini tiba tanpa berubah”. Di PowerShell, bandingkan keluarannya dengan baris di SHA256SUMS.txt (untuk installer, ganti .zip dengan .msi):

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

Tanda tangan menjawab pertanyaan lain, “apakah ini berasal dari repositori itu”, dan membutuhkan alat baris perintah GitHub:

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Ketik nama zip yang Anda unduh sebagai bagian pertama: gh tidak menerima * di sana. Pertahankan --predicate-type: tanpanya gh mencari jenis pernyataan yang lain dan melaporkan tidak menemukan apa pun.

Checksum yang Anda salin dari halaman yang sama dengan unduhannya membuktikan lebih sedikit daripada tanda tangan. Keduanya diterbitkan, jadi keduanya layak diperiksa sebentar.

Windows mungkin memperingatkan Anda

Program dan installer ditandatangani, sehingga Windows menyebut siapa yang menandatanganinya alih-alih mengatakan “Publisher tidak dikenal”. Sertifikatnya baru, jadi SmartScreen mungkin masih memperingatkan untuk sementara karena belum sering melihatnya. Itu soal sertifikat, bukan file, dan dua pemeriksaan di atas memungkinkan Anda memverifikasi file sendiri. Halaman pertanyaan membahas ini dan apa yang dibutuhkan driver.
