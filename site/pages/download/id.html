Unduh Bean Network Tester

Untuk Windows, zip yang berjalan tanpa menginstal apa pun, atau installer untuk semua pengguna di komputer. Apa pun pilihannya, program meminta hak administrator sendiri. Untuk Linux juga ada paket, sebagai uji coba.

{{cta.download}}

Fakta-fakta di satu tempat

  • Harga: gratis, dan perangkat lunak bebas: GNU GPL v3.
  • Berjalan di: Windows 10 dan Windows 11, 64-bit. Linux, sebagai uji coba: 64-bit (x86_64), diperiksa di Ubuntu 24.04 dan 26.04.
  • Membutuhkan: hak administrator, karena lalu lintas ditangkap oleh driver. Di Linux, hak root dan kernel 5.10 atau yang lebih baru.
  • Instalasi: tidak perlu. Ekstrak zip di mana saja lalu jalankan. Atau gunakan installer .msi, yang menambahkan entri Start Menu dan menaruh program di PATH (membutuhkan hak administrator). Di Linux, ekstrak .tar.gz.
  • Mengirim data: tidak ada dengan sendirinya. Tanpa telemetri, tanpa pengecekan pembaruan. Alat {{app.tools.ping.tab}} hanya mengirim ke alamat yang Anda ketik.
  • Mode: sebuah jendela, dan file yang sama sebagai alat baris perintah.
  • Kode sumber: di GitHub, dengan lisensi yang sama.

Isi rilis

Satu rilis menerbitkan delapan file. Tiga adalah programnya, dan lima lainnya ada agar Anda tidak perlu memercayai unduhan begitu saja:

  • zip: program dan driver yang dipakainya, bersama dalam satu folder;
  • installer .msi: program yang sama, dipasang untuk semua pengguna di komputer, dengan entri Start Menu;
  • .tar.gz: program untuk Linux, dengan Python-nya sendiri, sebagai uji coba;
  • SHA256SUMS.txt: checksum zip, installer, dan paket Linux;
  • dua SBOM: daftar standar setiap komponen di dalamnya, dengan versi dan lisensi, satu ditandatangani terhadap zip dan satu terhadap paket Linux;
  • dua file .sigstore.json: tanda tangan itu sebagai file, untuk memeriksanya tanpa bertanya ke GitHub.

Memastikan Anda menerima apa yang kami bangun

Checksum menjawab “apakah ini tiba tanpa berubah”. Di PowerShell, bandingkan keluarannya dengan baris di SHA256SUMS.txt (untuk installer, ganti .zip dengan .msi):

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

Tanda tangan menjawab pertanyaan lain, “apakah ini berasal dari repositori itu”, dan membutuhkan alat baris perintah GitHub:

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Di Linux, jalankan kedua pemeriksaan di folder tempat paket dan SHA256SUMS.txt berada:

sha256sum -c --ignore-missing SHA256SUMS.txt
gh attestation verify BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Ketik nama file yang Anda unduh sebagai bagian pertama: gh tidak menerima * di sana. Pertahankan --predicate-type: tanpanya gh mencari jenis pernyataan yang lain dan melaporkan tidak menemukan apa pun.

Checksum yang Anda salin dari halaman yang sama dengan unduhannya membuktikan lebih sedikit daripada tanda tangan. Keduanya diterbitkan, jadi keduanya layak diperiksa sebentar.

Windows mungkin memperingatkan Anda

Program dan installer ditandatangani, sehingga Windows menyebut siapa yang menandatanganinya alih-alih mengatakan “Publisher tidak dikenal”. Sertifikatnya baru, jadi SmartScreen mungkin masih memperingatkan untuk sementara karena belum sering melihatnya. Itu soal sertifikat, bukan file, dan dua pemeriksaan di atas memungkinkan Anda memverifikasi file sendiri. Halaman pertanyaan membahas ini dan apa yang dibutuhkan driver.

Di Linux

Paket ini adalah program yang sama dengan Python dan Tk-nya sendiri, jadi tidak ada yang perlu diinstal lebih dulu. Ekstrak, tambahkan ke menu aplikasi, lalu jalankan:

tar -xzf BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz
cd BeanNetworkTester
./BeanNetworkTester --install-desktop
./BeanNetworkTester

Jika dijalankan tanpa sudo, jendelanya meminta kata sandi administrator lewat dialog desktop itu sendiri. Paket ini membutuhkan glibc 2.38 atau yang lebih baru, jadi Ubuntu 22.04 dan Debian 12 terlalu lama untuknya. Dukungan Linux masih uji coba, dan README menjelaskan perbedaannya dengan Windows.
