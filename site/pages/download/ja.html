Bean Network Tester のダウンロード

Windows向けには、インストール不要で動くzip、またはコンピューター上のすべてのユーザー向けのインストーラーです。どちらでも、プログラムは自分で管理者権限を求めます。Linux向けにも、実験的なパッケージがあります。

{{cta.download}}

基本情報まとめ

  • 価格：無料。自由なソフトウェアで、GNU GPL v3です。
  • 動作環境：Windows 10およびWindows 11、64ビット。Linuxでも実験的に動作：64ビット（x86_64）、Ubuntu 24.04と26.04で確認済み。
  • 必要なもの：管理者権限。通信をドライバーで取得するためです。Linuxではroot権限とカーネル5.10以降。
  • インストール：不要です。zipをどこかに展開して実行してください。または .msi インストーラーを使うと、スタートメニューに項目が追加され、プログラムが PATH に入ります（管理者権限が必要です）。Linuxでは .tar.gz を展開します。
  • データの送信：自分からは何も送りません。テレメトリも更新確認もありません。{{app.tools.ping.tab}} ツールは、入力したアドレスにだけ送信します。
  • モード：ウィンドウと、同じファイルによるコマンドラインツール。
  • ソース：GitHub上に、同じライセンスで公開しています。

リリースの内容

リリースでは8つのファイルを公開します。3つがプログラム本体で、残りの5つは、ダウンロードを鵜呑みにしなくて済むようにするためのものです：

  • zip：プログラムと、それが使うドライバーを1つのフォルダーにまとめたもの。
  • .msiインストーラー：同じプログラムを、コンピューターのすべてのユーザー向けにインストールします。スタートメニューの項目付き。
  • .tar.gz：Linux向けのプログラム。専用のPythonを同梱した実験的なパッケージです。
  • SHA256SUMS.txt：zip、インストーラー、Linuxパッケージのチェックサム。
  • 2つのSBOM：内部の全コンポーネントを、バージョンとライセンス付きで並べた標準形式の一覧。1つはzipに、もう1つはLinuxパッケージに対して署名されています。
  • 2つの.sigstore.jsonファイル：それらの署名をファイルにしたもので、GitHubに問い合わせずに検証できます。

ビルドしたものを受け取ったことの確認

チェックサムが答えるのは「これは変更されずに届いたか」です。PowerShellで、出力を SHA256SUMS.txt の該当行と比較します（インストーラーの場合は .zip を .msi に置き換えます）：

Get-FileHash .\BeanNetworkTester-*.zip -Algorithm SHA256

署名が答えるのは別の問い、「これはそのリポジトリから出てきたものか」で、GitHubのコマンドラインツールが必要です：

gh attestation verify BeanNetworkTester-vX.Y.Z-windows-x64.zip --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

Linuxでは、パッケージと SHA256SUMS.txt があるフォルダーで、両方の確認を実行します：

sha256sum -c --ignore-missing SHA256SUMS.txt
gh attestation verify BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz --repo donislawdev/BeanNetworkTester --predicate-type https://spdx.dev/Document/v2.3

最初の部分には、ダウンロードしたファイルの名前を入力してください。gh はそこで * を受け付けません。--predicate-type は残してください。ないと gh は別の種類の証明を探し、見つからなかったと報告します。

ダウンロードと同じページからコピーしたチェックサムは、署名より証明力が弱くなります。どちらも公開しているので、どちらも確認する価値があります。

Windowsが警告を出すことがあります

プログラムとインストーラーは署名されているため、Windowsは「不明な発行元」ではなく、署名者を表示します。証明書は新しいため、SmartScreenはしばらく警告を出すかもしれません。まだ見かける機会が少ないからです。それは証明書の話でファイルの話ではなく、上の2つの確認で、ファイルは自分で検証できます。よくある質問のページに、これとドライバーが必要とするものについての説明があります。

Linuxの場合

パッケージは、専用のPythonとTkを同梱した同じプログラムなので、事前のインストールは不要です。展開し、アプリケーションメニューに追加して起動します：

tar -xzf BeanNetworkTester-vX.Y.Z-linux-x64.tar.gz
cd BeanNetworkTester
./BeanNetworkTester --install-desktop
./BeanNetworkTester

sudo なしで起動すると、ウィンドウはデスクトップのダイアログで管理者のパスワードを求めます。パッケージにはglibc 2.38以降が必要なため、Ubuntu 22.04やDebian 12では動きません。Linux対応は実験段階で、Windowsとの違いは README に書かれています。
