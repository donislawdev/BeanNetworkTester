จำลองแพ็กเก็ตสูญหายจากบรรทัดคำสั่ง

โปรแกรมเดียวกันทำงานได้โดยไม่ต้องเปิดหน้าต่าง ใส่ตัวเลือกใดก็ได้ แล้วมันจะทำงานในคอนโซลแทนหน้าต่าง สคริปต์หรืองาน CI ใช้งานมันแบบนี้

วิธีเริ่มทำงาน

บน Windows ก็คือ BeanNetworkTester.exe ตัวเดียวกับที่เปิดหน้าต่าง: ไม่มีตัวเลือกจะเปิดหน้าต่าง และเมื่อมีตัวเลือกใดก็ตามจะทำงานในคอนโซลโดยไม่แสดงหน้าต่าง หากใช้สำเนาซอร์สโค้ด ให้เขียน python bean_network_tester.py แทน บน Linux โปรแกรมคือ ./BeanNetworkTester ในโฟลเดอร์ที่คุณแตกไฟล์ไว้ และการดักจับจริงต้องใช้ sudo หน้า เครือข่ายแย่บน Linux บอกว่าที่นั่นต้องใช้อะไรอีกบ้าง

บรรทัดคำสั่งใช้ภาษาอังกฤษเสมอ ไม่ว่าหน้าต่างจะเป็นภาษาใด ข้อความของมันจึงอ่านเหมือนกันในทุกบันทึก

ลองแบบไม่มีความเสี่ยงก่อน

BeanNetworkTester.exe --simulate --loss 20 --duration 10
BeanNetworkTester.exe --doctor
BeanNetworkTester.exe --config my-settings.json --dry-run

คำสั่งแรกทำงานกับทราฟฟิกจำลอง จึงไม่ต้องใช้ไดรเวอร์หรือสิทธิ์ผู้ดูแลระบบ และแตะต้องเครือข่ายไม่ได้ คำสั่งที่สองตรวจคอมพิวเตอร์เครื่องนี้: สิทธิ์ที่การดักจับต้องใช้ ไดรเวอร์ดักจับ และสิ่งที่หลงเหลือจากการทำงานครั้งก่อน คำสั่งที่สามอ่านไฟล์การตั้งค่าและบอกว่าถูกต้องหรือไม่ โดยไม่เริ่มอะไรเลย

การตั้งค่ามาจากไหน

มีสี่แหล่ง แต่ละแหล่งเขียนทับแหล่งก่อนหน้า: ค่าเริ่มต้น ไฟล์การตั้งค่า (--config) โปรไฟล์สำเร็จรูป (--preset) และแฟล็กบนบรรทัดคำสั่ง --print-config แสดงผลลัพธ์เป็น JSON และ --save-config เขียนลงไฟล์ที่คุณโหลดกลับมาได้ ทั้งในหน้าต่างและบนบรรทัดคำสั่ง

การตั้งค่าทุกรายการในหน้าต่างมีแฟล็กของตัวเอง เช่น --loss หรือ --target รายการเหล่านี้พร้อมหน้าที่ของแต่ละตัวอยู่ในหน้าตารางอ้างอิง ตัวเลือกด้านล่างคือที่เหลือทั้งหมด

มันพิมพ์อะไรออกมา

บันทึกสำหรับคนอ่านจะไปที่ช่องข้อผิดพลาดมาตรฐาน และทุกบรรทัดขึ้นต้นด้วย [bean] ข้อมูลจะไปที่เอาต์พุตมาตรฐาน: บรรทัดรายงานทุก ๆ ไม่กี่วินาที และสรุปตอนท้าย เมื่อใช้ --format json เอาต์พุตมาตรฐานจะมีอ็อบเจ็กต์ JSON บรรทัดละหนึ่งตัว: อ็อบเจ็กต์ sample สำหรับแต่ละรายงาน และ summary ตอนท้ายที่มีรหัสออก seed และคำสั่งที่ทำซ้ำการทำงานนั้น

BeanNetworkTester.exe --simulate --duration 30 --format json > run.ndjson

การทำงานจบได้แต่ละแบบมีรหัสออกของตัวเอง ไปป์ไลน์จึงแยกได้ว่าแอปพลิเคชันล้มเหลวหรือเครื่องมือเริ่มไม่ได้ รหัสทั้งหมดอยู่ในหน้าตารางอ้างอิง

ตัวอย่าง

ทำให้เครือข่ายของโปรแกรมเดียวแย่ลงหนึ่งนาที โดยไม่แตะอย่างอื่นบนคอมพิวเตอร์:

BeanNetworkTester.exe --target myapp.exe --latency 200 --loss 2 --duration 60

ทำให้การเชื่อมต่อกับเซิร์ฟเวอร์เดียวแย่ลงสองนาที พร้อมเอาต์พุตที่ไปป์ไลน์อ่านได้ และให้ล้มเหลวหากไม่ได้ดักจับอะไรเลย:

BeanNetworkTester.exe --dst-ip 10.0.0.5 --dst-port 443 --loss 5 --duration 120 --format json --fail-on-no-traffic

เล่นวนสถานการณ์จำลองสำเร็จรูปที่ไม่วนซ้ำเองเป็นเวลาสิบนาที และเก็บรายงานที่ทำซ้ำการทำงานนั้นไว้:

BeanNetworkTester.exe --scenario scenarios/upload-drop-midway.json --loop --target myapp.exe --duration 600 --repro-out run.json

สูตรเพิ่มเติมสำหรับไปป์ไลน์อยู่ที่การทดสอบเครือข่ายใน CI
