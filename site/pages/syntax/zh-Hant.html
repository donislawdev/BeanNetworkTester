篩選語法：名稱、PID、IP 範圍、CIDR 和連接埠

一種小小的語言讓工具針對程式、位址和連接埠。它在視窗和命令列中的用法完全一樣，本頁上的每個範例都由程式自己的剖析器檢查過。

在哪裡使用

在視窗中：目標處理程序欄位、{{app.frames.destination}}和{{app.frames.block}}下的位址與連接埠欄位，以及兩個資料長度欄位。在命令列中：--target、--dst-ip、--dst-port、--block-ip、--block-port、--payload-udp 和 --payload-tcp。欄位留空表示全部。

基本寫法

寫法意思範例
a,b,c清單：任一項符合即可80,443
a-b範圍，包含兩端10.0.0.1-10.0.0.50
> < >= <=比較，用於數字和位址>1024
!排除這一項!53
* ?萬用字元：任意一串字元，或一個字元chrome*
re:規則運算式，不分大小寫re:^chrome\.exe$
a.b.c.d/nCIDR 區段，只用於位址192.168.1.0/24

逗號兩側的空格會被忽略，兩個逗號之間的空位也會被忽略。! 後面什麼都沒有則是錯誤：80,! 會被拒絕。

各項如何組合

不帶 ! 的項相加：只要其中任一項符合，或者根本沒有這樣的項，值就符合。帶 ! 的項隨後把符合的去掉。順序無關，所以 80,!53 與 !53,80 相同。

寫法符合
443只有 443 連接埠
!5353 以外的一切，因為沒有要相加的項
!53,!44353 和 443 以外的一切
1000-2000,!15001000 到 2000，不含 1500
80,443,8000-8100,>9000,!808080、443、8000 到 8100 以及 9000 以上的一切，但不含 8080

程式

一項可以是名稱或 PID，一個欄位中可以混用。一般名稱會在程式名稱的任何位置比對，不分大小寫，所以 chrome 會符合 chrome.exe 和 chromedriver.exe。單獨的數字、範圍或比較表示 PID。萬用字元和 re: 比對名稱。對名稱做比較（例如 >chrome）會被拒絕，而不是什麼都不符合。

寫法符合
chrome.exe名稱中含有 chrome.exe 的所有程式
chrome,!chromedriverChrome，但不含 chromedriver
chrome.exe,firefox.exe同時兩個程式
12345一個 PID
1000-2000該範圍內的所有 PID
firefox*以 firefox 開頭的名稱
re:^(chrome|firefox)\.exe$恰好是 chrome.exe 或 firefox.exe
firefox,12345一個欄位中同時寫名稱和 PID

封包只攜帶位址和連接埠，從不攜帶程式名稱，所以工具會找出每個符合的程式占用的本機連接埠並針對這些連接埠，同時追蹤它新開啟的連線。少數連接埠會被多個程式同時共用（mDNS 5353、SSDP 1900、DHCP 67 和 68）。在這些連接埠上只能全有或全無，記錄中會說明是哪一種。

位址

IPv4 和 IPv6 都支援，一個欄位中可以混用：針對一種位址族的規則永遠不會符合另一種位址族的位址。位址的寫法無關緊要，所以 2001:0db8:0000:0000:0000:0000:0000:0001 和 2001:db8::1 是同一個位址。

寫法符合
1.2.3.4,8.8.8.8兩個位址
10.0.0.1-10.0.0.50,!10.0.0.7中間挖掉一個的範圍
192.168.1.0/24整個子網路
192.168.1.*同一個子網路，用萬用字元表示
!8.8.8.88.8.8.8 以外的所有位址
2001:db8::/32一個 IPv6 子網路
10.0.0.0/8,2001:db8::/32一個欄位中同時有 IPv4 和 IPv6

連接埠

連接埠範圍是 0 到 65535；99999 會被拒絕，而不是被略過。資料長度欄位使用相同的語法，以資料位元組數計算。

寫法符合
8000-8100範圍，包含兩端
>1024高位連接埠
<=1024特權連接埠
80,443,8000-8100,!8080混合寫法

規則運算式

只有前面加上 re: 的項才是規則運算式，所以 chrome.exe 中的點仍然是點。模式不分大小寫，可以在文字的任何位置符合；要符合整段文字，請使用 ^ 和 $。模式中的逗號需要加反斜線，因為逗號用來分隔各項：re:^ch.{1\,8}e\.exe$ 可以正常使用。如果不加反斜線，re:^ch.{1,8}e\.exe$ 會在逗號處被切成兩項，兩項都能載入，但符合的是別的東西。

重複裡面再套重複，例如 re:^(\w+)+$，會因為太慢而被拒絕：遇到一個幾乎符合的名稱就可能耗費數秒，而位址在每個封包上都要檢查。請只寫一次重複：re:^\w+$。

容易踩的坑

  • chrome 會符合 chromedriver，而 chrome.exe 不會：一般名稱只是名稱的一部分。
  • chrome* 也會符合 chromedriver。要恰好符合一個程式，請寫 re:^chrome\.exe$。
  • 連接埠欄位中的 8* 是針對數字文字的萬用字元，所以它符合 8、80、8080 和 8443，但不符合 443。你幾乎總是想要一個範圍，例如 8000-8999。
  • !53 也包括完全沒有連接埠的流量，例如 ping，因為 ping 封包不是 53 連接埠。
  • 同時設定了位址和連接埠時，兩者都必須符合。如果只想滿足其中之一，請分兩次執行。
  • 倒著寫的範圍 2000-1000 會被拒絕。
  • 萬用字元不是規則運算式：在 re:chrome* 中，星號重複的是字母 e。

每個錯誤都會立即回報：視窗中的欄位變紅，並在下方顯示原因；命令列則以一則易讀的訊息結束。
