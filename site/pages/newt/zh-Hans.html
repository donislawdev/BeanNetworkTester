NEWT（Network Emulator for Windows Toolkit）的替代方案

NEWT 是微软为 Windows 做的网络模拟器。它给真实流量加上延迟、丢包和限速，让人在普通电脑上就能看程序在差网络下的表现。微软已不再提供它的下载。本页把 NEWT 的每项设置对应到 Bean Network Tester，它在 Windows 10 和 11 上做同样的事。

NEWT 后来怎么样了

  • NEWT 随 Games for Windows LIVE SDK 和 Xbox 开发工具包一起发布。后来它的驱动进入了 Visual Studio 2010，成为负载测试中的网络模拟。
  • 微软已弃用 Visual Studio 中的 Web 性能和负载测试，网络模拟也在其中。Visual Studio 2019 是完整提供这些功能的最后一个版本。
  • 如今微软不再提供下载。搜索能找到的是下载站上的副本，以及一个最后更新于 2013 年的 Chocolatey 包。

模拟器会安装网络驱动，并以管理员权限运行，所以运行安装程序之前，最好先弄清它的来源。

逐项对照 NEWT 的设置

本页的每条命令都要加上 --target 和 --duration，否则会影响整台电脑。

NEWT 中窗口中的设置参数
延迟（Latency）{{app.fields.latency}}；延迟需要波动时再加 {{app.fields.jitter}}--latency 100 --jitter 20
带宽（Bandwidth）{{app.fields.download}}、{{app.fields.upload}}--down 1221 --up 1221
队列（Queue）{{app.fields.buffer}}--buffer 1000
丢包（Packet loss）{{app.fields.loss}}；丢包成串出现时再加 {{app.fields.loss_burst}}--loss 5 --loss-burst 4
乱序（Reordering）{{app.fields.spike_prob}}、{{app.fields.spike_ms}}--spike-prob 5 --spike-ms 200
错误（Errors）{{app.fields.corruption}}--corrupt 0.1
断开与重连{{app.frames.flapping}}--flap-period 10 --flap-down 40
按 IP 地址过滤{{app.frames.destination}}--dst-ip 10.0.0.5
按协议过滤{{app.frames.traffic}}：{{app.filters.tcp}}、{{app.filters.udp}} 或 {{app.filters.ping}}--filter tcp
  • 速度。限速字段的单位是 KB/s，K = 1024：122 约等于 1 Mbit/s，1221 约等于 10 Mbit/s。netem 页面有一张更长的换算表。
  • 队列。{{app.fields.buffer}} 是以毫秒计的时间，而不是数据包个数。
  • 乱序。没有乱序百分比。一次延迟尖峰会拖住单个数据包，让之后发送的包超过它，{{app.app.tabs.statistics}}页面上的乱序计数会显示是否真的发生了。
  • 两个方向。每个值在去程和回程都会生效，所以 --latency 100 会让 ping 增加约 200 毫秒。要为两个方向分别设置，请勾选 {{app.fields.asym}}，或加上 --asym 和以 -up 结尾的参数。

一条典型的 NEWT 链路写成一条命令，只针对一个程序，持续两分钟：

BeanNetworkTester.exe --latency 100 --jitter 20 --loss 2 --down 1221 --up 1221 --target myapp.exe --duration 120

这个工具带来什么

  • 针对一个程序，而不是整台电脑。除了地址和协议，过滤条件还可以是一个程序，按名称或进程 ID 指定。把网络损伤对准单个应用，机器上的其他部分保持正常。
  • 带退出码的命令行。同一个可执行文件可以在 CI 中运行，并用退出码报告每一种结果。
  • 可以重复的运行。使用 --seed，下一次运行会出现同样的随机丢包和抖动。
  • 会自己变化的设置。定时场景在设定的秒数切换设置，你只需看着程序。
  • 实时视图。图表、计数器和连接表显示哪些连接被影响、影响了多少。
  • 同一窗口里的网络工具。带图表的持续 ping、端口扫描和 NAT 类型测试。

什么时候该用别的工具

  • 你需要由路由器和交换机组成的整个网络。那是网络仿真器的工作，例如 GNS3 或 EVE-NG，它们运行虚拟设备。模拟器改变的是一台真实电脑的流量。
  • 你想要有技术支持的商业产品。SoftPerfect Connection Emulator 是一款付费的 Windows 网络模拟器。
  • 你在用 Linux。tc netem 是内置的，这个工具在 Linux 上也能运行，属于实验性支持。请看在 Linux 上模拟差网络。
  • 你拿不到管理员权限。无论用哪个工具，改变其他程序的流量都需要它。
