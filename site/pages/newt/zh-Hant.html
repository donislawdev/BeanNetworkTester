NEWT（Network Emulator for Windows Toolkit）的替代方案

NEWT 是微軟為 Windows 做的網路模擬器。它在真實流量上加入延遲、封包遺失和限速，讓人在一般電腦上就能看程式在差網路下的表現。微軟已不再提供下載。本頁把 NEWT 的每項設定對應到 Bean Network Tester，它在 Windows 10 和 11 上做同樣的事。

NEWT 後來怎麼了

  • NEWT 隨 Games for Windows LIVE SDK 和 Xbox 開發套件一起發佈。後來它的驅動程式進入了 Visual Studio 2010，成為負載測試中的網路模擬。
  • 微軟已淘汰 Visual Studio 中的 Web 效能與負載測試，網路模擬也包含在內。Visual Studio 2019 是完整提供這些功能的最後一個版本。
  • 如今微軟不再提供下載。搜尋能找到的是下載網站上的副本，以及一個最後更新於 2013 年的 Chocolatey 套件。

模擬器會安裝網路驅動程式，並以系統管理員權限執行，所以執行安裝程式之前，最好先弄清楚它的來源。

逐項對照 NEWT 的設定

本頁的每條命令都要加上 --target 和 --duration，否則會影響整台電腦。

NEWT 中視窗中的設定參數
延遲（Latency）{{app.fields.latency}}；延遲需要變動時再加 {{app.fields.jitter}}--latency 100 --jitter 20
頻寬（Bandwidth）{{app.fields.download}}、{{app.fields.upload}}--down 1221 --up 1221
佇列（Queue）{{app.fields.buffer}}--buffer 1000
封包遺失（Packet loss）{{app.fields.loss}}；遺失成串出現時再加 {{app.fields.loss_burst}}--loss 5 --loss-burst 4
亂序（Reordering）{{app.fields.spike_prob}}、{{app.fields.spike_ms}}--spike-prob 5 --spike-ms 200
錯誤（Errors）{{app.fields.corruption}}--corrupt 0.1
斷線與重新連線{{app.frames.flapping}}--flap-period 10 --flap-down 40
依 IP 位址篩選{{app.frames.destination}}--dst-ip 10.0.0.5
依通訊協定篩選{{app.frames.traffic}}：{{app.filters.tcp}}、{{app.filters.udp}} 或 {{app.filters.ping}}--filter tcp
  • 速度。限速欄位的單位是 KB/s，K = 1024：122 約等於 1 Mbit/s，1221 約等於 10 Mbit/s。netem 頁面有一張更長的換算表。
  • 佇列。{{app.fields.buffer}} 是以毫秒計的時間，而不是封包數量。
  • 亂序。沒有亂序百分比。一次延遲尖峰會拖住單一封包，讓之後送出的封包超過它，{{app.app.tabs.statistics}}頁面上的亂序計數會顯示是否真的發生了。
  • 兩個方向。每個值在去程和回程都會生效，所以 --latency 100 會讓 ping 增加約 200 毫秒。要為兩個方向分別設定，請勾選 {{app.fields.asym}}，或加上 --asym 和以 -up 結尾的參數。

一條典型的 NEWT 連線寫成一條命令，只針對一個程式，持續兩分鐘：

BeanNetworkTester.exe --latency 100 --jitter 20 --loss 2 --down 1221 --up 1221 --target myapp.exe --duration 120

這個工具帶來什麼

  • 針對一個程式，而不是整台電腦。除了位址和通訊協定，篩選條件還可以是一個程式，依名稱或處理程序 ID 指定。把網路劣化對準單一應用程式，電腦的其他部分保持正常。
  • 有結束代碼的命令列。同一個執行檔可以在 CI 中執行，並用結束代碼回報每一種結果。
  • 可以重複的執行。使用 --seed，下一次執行會出現同樣的隨機封包遺失和抖動。
  • 會自己變化的設定。定時情境在設定的秒數切換設定，你只需看著程式。
  • 即時檢視。圖表、計數器和連線表顯示哪些連線受到影響、影響了多少。
  • 同一視窗裡的網路工具。有圖表的持續 ping、連接埠掃描和 NAT 類型測試。

什麼時候該用別的工具

  • 你需要由路由器和交換器組成的整個網路。那是網路模擬平台的工作，例如 GNS3 或 EVE-NG，它們執行虛擬裝置。模擬器改變的是一台真實電腦的流量。
  • 你想要有技術支援的商業產品。SoftPerfect Connection Emulator 是一款付費的 Windows 網路模擬器。
  • 你在用 Linux。tc netem 是內建的，這個工具在 Linux 上也能執行，屬於實驗性支援。請看在 Linux 上模擬差網路。
  • 你拿不到系統管理員權限。無論用哪個工具，改變其他程式的流量都需要它。
