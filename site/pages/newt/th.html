ทางเลือกแทน NEWT หรือ Network Emulator for Windows Toolkit

NEWT เป็นโปรแกรมจำลองเครือข่ายของ Microsoft สำหรับ Windows มันเพิ่มความหน่วง การสูญหายของแพ็กเก็ต และการจำกัดความเร็วให้กับทราฟฟิกจริง เพื่อให้ลองโปรแกรมบนเครือข่ายที่แย่ได้จากพีซีธรรมดา ตอนนี้ Microsoft ไม่ได้ให้ดาวน์โหลดแล้ว หน้านี้จับคู่การตั้งค่าแต่ละอย่างของ NEWT กับ Bean Network Tester ซึ่งทำงานแบบเดียวกันบน Windows 10 และ 11

เกิดอะไรขึ้นกับ NEWT

  • NEWT มาพร้อมกับ Games for Windows LIVE SDK และชุดพัฒนาสำหรับ Xbox ต่อมาไดรเวอร์ของมันถูกย้ายเข้าไปใน Visual Studio 2010 เป็นการจำลองเครือข่ายในการทดสอบโหลด
  • Microsoft ประกาศเลิกใช้การทดสอบประสิทธิภาพเว็บและการทดสอบโหลดใน Visual Studio รวมถึงการจำลองเครือข่ายด้วย Visual Studio 2019 เป็นเวอร์ชันสุดท้ายที่มีความสามารถเหล่านี้ครบถ้วน
  • วันนี้ไม่มีให้ดาวน์โหลดจาก Microsoft แล้ว การค้นหาจะเจอสำเนาบนเว็บดาวน์โหลด และแพ็กเกจ Chocolatey ที่อัปเดตครั้งล่าสุดในปี 2013

โปรแกรมจำลองจะติดตั้งไดรเวอร์เครือข่ายและทำงานด้วยสิทธิ์ผู้ดูแลระบบ ดังนั้นก่อนเรียกใช้ตัวติดตั้ง ควรรู้ก่อนว่ามันมาจากไหน

การตั้งค่าของ NEWT ทีละอย่าง

เติม --target และ --duration ในทุกคำสั่งบนหน้านี้ ไม่อย่างนั้นคำสั่งจะมีผลกับทั้งคอมพิวเตอร์

ใน NEWTการตั้งค่าในหน้าต่างแฟลก
ความหน่วง (Latency){{app.fields.latency}} และ {{app.fields.jitter}} สำหรับความหน่วงที่ไม่คงที่--latency 100 --jitter 20
แบนด์วิดท์ (Bandwidth){{app.fields.download}}, {{app.fields.upload}}--down 1221 --up 1221
คิว (Queue){{app.fields.buffer}}--buffer 1000
การสูญหายของแพ็กเก็ต (Packet loss){{app.fields.loss}} และ {{app.fields.loss_burst}} สำหรับการสูญหายที่มาติดกันเป็นชุด--loss 5 --loss-burst 4
การสลับลำดับ (Reordering){{app.fields.spike_prob}}, {{app.fields.spike_ms}}--spike-prob 5 --spike-ms 200
ข้อผิดพลาด (Errors){{app.fields.corruption}}--corrupt 0.1
การหลุดและการเชื่อมต่อใหม่{{app.frames.flapping}}--flap-period 10 --flap-down 40
กรองตามที่อยู่ IP{{app.frames.destination}}--dst-ip 10.0.0.5
กรองตามโปรโตคอล{{app.frames.traffic}}: {{app.filters.tcp}}, {{app.filters.udp}} หรือ {{app.filters.ping}}--filter tcp
  • ความเร็ว ช่องจำกัดความเร็วมีหน่วยเป็น KB/s โดย K = 1024 ค่า 122 เท่ากับประมาณ 1 Mbit/s และ 1221 ประมาณ 10 Mbit/s หน้า netem มีตารางที่ยาวกว่านี้
  • คิว {{app.fields.buffer}} เป็นเวลาในหน่วยมิลลิวินาที ไม่ใช่จำนวนแพ็กเก็ต
  • การสลับลำดับ ไม่มีค่าเปอร์เซ็นต์ของการสลับลำดับ สไปก์จะกักแพ็กเก็ตไว้หนึ่งตัว ให้แพ็กเก็ตที่ส่งตามหลังแซงไป และตัวนับแพ็กเก็ตที่สลับลำดับในหน้า {{app.app.tabs.statistics}} จะบอกว่าเกิดขึ้นจริงหรือไม่
  • ทั้งสองทิศทาง ทุกค่ามีผลทั้งขาไปและขากลับ ดังนั้น --latency 100 จะเพิ่มเวลา ping ราว 200 ms ถ้าต้องการค่าที่ต่างกันในแต่ละทิศทาง ให้ติ๊ก {{app.fields.asym}} หรือเติม --asym กับแฟลกที่ลงท้ายด้วย -up

ลิงก์ NEWT แบบทั่วไปเขียนเป็นคำสั่งเดียว เล็งไปที่โปรแกรมเดียวเป็นเวลาสองนาที

BeanNetworkTester.exe --latency 100 --jitter 20 --loss 2 --down 1221 --up 1221 --target myapp.exe --duration 120

เครื่องมือนี้ให้อะไร

  • โปรแกรมเดียว ไม่ใช่ทั้งคอมพิวเตอร์ นอกจากที่อยู่และโปรโตคอลแล้ว ตัวกรองยังเป็นโปรแกรมได้ด้วย โดยระบุชื่อหรือ ID ของโปรเซส เล็งความเสียหายไปที่แอปเดียว ขณะที่ส่วนอื่นของเครื่องยังทำงานตามปกติ
  • บรรทัดคำสั่งที่มีรหัสออก ไฟล์โปรแกรมเดียวกันทำงานใน CI และรายงานทุกผลลัพธ์ด้วยรหัสออก
  • การรันที่ทำซ้ำได้ เมื่อใช้ --seed การสูญหายแบบสุ่มและจิตเตอร์ชุดเดิมจะกลับมาในการรันครั้งถัดไป
  • การตั้งค่าที่เปลี่ยนเอง สถานการณ์ตามเวลาจะสลับการตั้งค่าในวินาทีที่กำหนด ขณะที่คุณดูโปรแกรมอยู่
  • มุมมองแบบสด กราฟ ตัวนับ และตารางการเชื่อมต่อแสดงว่าอะไรโดนผลกระทบและมากแค่ไหน
  • เครื่องมือเครือข่ายในหน้าต่างเดียวกัน ping ต่อเนื่องพร้อมกราฟ เครื่องสแกนพอร์ต และการทดสอบประเภท NAT

เมื่อไรควรใช้อย่างอื่น

  • คุณต้องการเครือข่ายทั้งวงที่มีเราเตอร์และสวิตช์ นั่นเป็นงานของโปรแกรมจำลองเครือข่ายแบบ GNS3 หรือ EVE-NG ที่รันอุปกรณ์เสมือน ส่วนโปรแกรมจำลองแบบนี้เปลี่ยนทราฟฟิกของคอมพิวเตอร์จริงเครื่องเดียว
  • คุณต้องการผลิตภัณฑ์เชิงพาณิชย์ที่มีการสนับสนุน SoftPerfect Connection Emulator เป็นโปรแกรมจำลองเครือข่ายแบบเสียเงินสำหรับ Windows
  • คุณใช้ Linux tc netem มีมาให้ในระบบอยู่แล้ว และเครื่องมือนี้ก็ทำงานบน Linux ได้ในแบบทดลอง ดูเครือข่ายแย่บน Linux
  • คุณขอสิทธิ์ผู้ดูแลระบบไม่ได้ การเปลี่ยนทราฟฟิกของโปรแกรมอื่นต้องใช้สิทธิ์นี้ ไม่ว่าจะใช้เครื่องมือใด

กำลังเปรียบเทียบเครื่องมือฟรีสำหรับ Windows อยู่ใช่ไหม หน้าทางเลือกแทน Clumsyพูดถึง Clumsy, NetLimiter และพร็อกซีอย่าง Fiddler
