ping ต่อเนื่องที่จดตัวเลขไว้ให้คุณ

ping ต่อเนื่องเป็นวิธีที่เร็วที่สุดในการดูว่าการเชื่อมต่อเสถียรหรือไม่ โดยส่งคำขอ echo ทีละครั้งไปเรื่อย ๆ จนกว่าคุณจะหยุด ทั้ง Windows และ Linux มีให้ในคอนโซล เครื่องมือ {{app.tools.ping.tab}} ในแท็บ {{app.app.tabs.tools}} ทำแบบเดียวกันและเก็บตัวเลขที่คอนโซลปล่อยให้คุณนับเอง ได้แก่ จิตเตอร์ ช่วงสูญหายต่อเนื่องที่ยาวที่สุด และเวลาไปกลับที่คำตอบ 95% ไม่เกิน

ในคอนโซล

ใน Command Prompt ของ Windows ตัวเลือก -t จะ ping ไปจนกว่าคุณจะกด Ctrl+C ส่วน Ctrl+Break จะแสดงยอดรวมจนถึงตอนนั้นแล้วทำงานต่อ

ping -t 1.1.1.1

หากต้องการเก็บผลลัพธ์ไว้ในไฟล์ หรือใส่เวลาในทุกบรรทัด ให้ใช้ PowerShell:

ping -t 1.1.1.1 > ping.txt
ping.exe -t 1.1.1.1 | ForEach-Object { "{0:HH:mm:ss} {1}" -f (Get-Date), $_ }

PowerShell 7 มีคำสั่งของตัวเองสำหรับเรื่องนี้ และบน Linux คำสั่ง ping ปกติก็ทำงานไปจนกด Ctrl+C อยู่แล้ว -D จะใส่เวลากำกับในทุกบรรทัด

Test-Connection 1.1.1.1 -Repeat
ping -D 1.1.1.1

ไม่มีคำสั่งไหนสรุปผลระหว่างที่กำลังทำงาน คุณจะได้หนึ่งบรรทัดต่อหนึ่งคำตอบ และยอดรวมตอนท้าย

ด้วยเครื่องมือ {{app.tools.ping.tab}}

  • พิมพ์ที่อยู่หรือชื่อ เลือกว่าจะ ping บ่อยแค่ไหน จะรอคำตอบนานเท่าไร แต่ละ ping มีข้อมูลกี่ไบต์ (32 แบบที่ ping.exe ส่ง สูงสุด 65 500) และจะส่งกี่ ping หรือปล่อยให้ทำงานไปจนกด {{app.tools.ping.stop}} แล้วกด {{app.tools.ping.start}}
  • แต่ละ ping คือหนึ่งแถว ได้แก่ เวลาที่ส่งออก เวลาไปกลับ TTL และสิ่งที่ตอบกลับมา กราฟแสดงเวลาไปกลับของ 60 ครั้งล่าสุด
  • บรรทัดเหนือตารางเก็บยอดรวม ได้แก่ ส่งแล้ว คำตอบ สูญหาย ช่วงสูญหายต่อเนื่องที่ยาวที่สุด เวลาไปกลับต่ำสุด เฉลี่ย และสูงสุด จิตเตอร์ (เวลาไปกลับขยับมากแค่ไหนจากคำตอบหนึ่งไปยังคำตอบถัดไป) และเวลาที่คำตอบ 95% ไม่เกิน
  • มันยัง ping ต่อไปแม้แท็บอื่นอยู่ด้านหน้า คลิกขวาที่แถวใน {{app.tools.sockets.tab}} หรือ {{app.app.tabs.connections}} แล้วเลือก {{app.menu.ping_address}} เพื่อ ping ปลายอีกด้าน
  • {{app.tools.ping.copy}} จะคัดลอกแถวและยอดรวมเป็นภาษาอังกฤษ สำหรับรายงานบั๊ก

คำตอบที่มาถึงหลังเวลารอจะนับว่าสูญหาย ถ้าความหน่วงสูง ให้เลือกเวลารอที่นานขึ้น

ดูเครือข่ายแย่มาถึง

เริ่ม ping แล้วเริ่มเซสชันในหน้าควบคุมพร้อมความหน่วงและการสูญหายเล็กน้อย เมื่อเซสชันเริ่ม หยุด ได้รับการตั้งค่าใหม่ หรือขยับไปขั้นถัดไปของสถานการณ์ บรรทัดนั้นจะแสดงเวลานับจากตอนนั้น และค่าเฉลี่ยเวลาไปกลับกับสัดส่วนที่สูญหายต่างจากก่อนหน้าเท่าไร ส่วนกราฟจะทำเครื่องหมายช่วงเวลานั้นด้วยเส้นประ อีกบรรทัดหนึ่งบอกว่าเซสชันทำอะไรกับ ping เหล่านี้ คือทำให้เสีย มองเห็นแต่ปล่อยไว้ หรือไม่ได้ดักจับเลย

เมื่อใช้ตัวกรองทราฟฟิกค่าเริ่มต้น ping หนึ่งครั้งจะรับความหน่วงสองรอบ ความหน่วง 100 ms จึงเพิ่มเวลาไปกลับราว 200 ms และการสูญหายจะกระทบคำขอและคำตอบแยกกัน การสูญหาย 20% จึงทำให้ ping หายไปราวหนึ่งในสาม เซสชันที่เล็งโปรแกรมเดียวจะไม่แตะ ping เลย เพราะ ping ไม่ได้เป็นของการเชื่อมต่อของโปรแกรมใด ในกรณีนี้ให้เล็งที่ที่อยู่แทน

บน Linux

เครื่องมือนี้ใช้บน Linux ได้เช่นกัน ไม่ต้องใช้ sudo ในระบบที่อนุญาตให้กลุ่มของคุณส่ง ping เช่น Ubuntu 26.04 และต้องใช้ในระบบที่ไม่อนุญาต เช่น Ubuntu 24.04 ส่วนที่เหลืออยู่ใน หน้า Linux
