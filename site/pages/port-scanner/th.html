พอร์ตไหนของคอมพิวเตอร์อีกเครื่องที่ตอบกลับ

เครื่องสแกนพอร์ตจะถามคอมพิวเตอร์ทีละพอร์ตว่ามีอะไรตอบกลับอยู่ตรงนั้นหรือไม่ เครื่องมือ {{app.tools.portscan.tab}} ในแท็บ {{app.app.tabs.tools}} ทำแบบนี้ผ่าน TCP และ UDP จากหน้าต่าง ทั้งบน Windows และ Linux และบอกด้วยคำพูดง่าย ๆ ว่าผลลัพธ์หมายถึงอะไร สแกนเฉพาะคอมพิวเตอร์ที่คุณได้รับอนุญาตให้ทดสอบเท่านั้น เพราะซอฟต์แวร์ความปลอดภัยและผู้ดูแลเครือข่ายมองเห็นการสแกนได้

วิธีเริ่มการสแกน

  1. เปิดแท็บ {{app.app.tabs.tools}} แล้วไปที่ {{app.tools.group.network}} และ {{app.tools.portscan.tab}}
  2. พิมพ์ที่อยู่หรือชื่อคอมพิวเตอร์ และพอร์ตแบบเดียวกับที่พิมพ์ในหน้าควบคุม เช่น 22, 80, 443 หรือ 8000-8100 หรือเติมด้วย {{app.tools.portscan.common}} (บริการที่ใช้บ่อยและเซิร์ฟเวอร์สำหรับพัฒนา), {{app.tools.portscan.well_known}} หรือ {{app.tools.portscan.all}}
  3. ติ๊ก {{app.tools.portscan.tcp}}, {{app.tools.portscan.udp}} หรือทั้งสอง แล้วกด {{app.tools.portscan.scan}} ส่วน {{app.tools.portscan.stop}} จะจบการสแกนก่อนกำหนด พร้อมผลของพอร์ตที่ถามไปแล้ว

พอร์ตที่อยู่ติดกันและได้คำตอบเหมือนกันจะรวมเป็นแถวเดียว ข้างบริการที่พอร์ตนั้นมักใช้ และบรรทัดเหนือตารางจะบอกว่าผลลัพธ์หมายถึงอะไร

คำตอบแต่ละแบบหมายถึงอะไร

คำตอบความหมาย
{{app.tools.portscan.state.open}}บน TCP มีโปรแกรมรับการเชื่อมต่อที่พอร์ตนั้น บน UDP มีบริการตอบคำขอ
{{app.tools.portscan.state.closed}}คอมพิวเตอร์ตอบว่าไม่มีอะไรรอรับอยู่ตรงนั้น
{{app.tools.portscan.state.silent}}ไม่มีอะไรตอบกลับมาทันเวลา บน TCP มักเป็นไฟร์วอลล์ที่ทิ้งคำขอ บน UDP พอร์ตอาจเปิดอยู่ก็ได้ เพราะบริการที่ไม่เข้าใจคำขอจะเงียบ
{{app.tools.portscan.state.unreachable}}ระบบบอกว่าไม่มีคอมพิวเตอร์เครื่องนั้น อาจปิดอยู่ หรือนี่ไม่ใช่ที่อยู่ของมัน
{{app.tools.portscan.state.denied}}คอมพิวเตอร์เครื่องนี้ปฏิเสธที่จะส่งคำขอ

บน Windows พอร์ต UDP ที่ปิดจะแสดงเป็น {{app.tools.portscan.state.closed}} ก็ต่อเมื่อโปรแกรมทำงานในฐานะผู้ดูแลระบบ ไฟร์วอลล์ของ Windows ซ่อนข้อความนั้นจากโปรแกรม และเมื่อมีสิทธิ์ผู้ดูแลระบบ เครื่องมือจะอ่านจากสำเนาของทราฟฟิกเครือข่าย หากไม่มีสิทธิ์ พอร์ต UDP ที่ปิดจะแสดงเป็น {{app.tools.portscan.state.silent}}

ส่งอะไรออกไป และเร็วแค่ไหน

  • บน TCP คือการเชื่อมต่อที่ปิดทันทีโดยไม่ส่งอะไรผ่านมัน บน UDP คือคำขอจริงสำหรับ DNS, NTP, NetBIOS, mDNS และ SSDP และดาตาแกรมว่างสำหรับพอร์ตอื่นทั้งหมด
  • คอมพิวเตอร์ในเครือข่ายที่เครื่องนี้เชื่อมอยู่จะถูกถามครั้งละ 256 พอร์ต พอร์ตละ 1 วินาที เครื่องที่อยู่หลังเราเตอร์จะถูกถามครั้งละ 32 พอร์ต เพิ่มใหม่ไม่เกิน 20 ต่อวินาที พอร์ตละ 3 วินาที เพื่อไม่ให้ตารางการเชื่อมต่อของเราเตอร์เต็ม การสแกนที่อาจนานเกินห้านาทีจะถามก่อน
  • เมื่อ 64 พอร์ตแสดง {{app.tools.portscan.state.unreachable}} และไม่มีพอร์ตอื่นตอบเลย แปลว่าไม่มีคอมพิวเตอร์เครื่องนั้น และการสแกนจะหยุดถามมัน
  • เมื่อมีเพียงไม่กี่พอร์ตที่ไม่ตอบ ขณะที่พอร์ตอื่นตอบ พอร์ตไม่กี่พอร์ตนั้นจะถูกถามอีกครั้งอย่างช้าลง

{{app.tools.portscan.copy}} จะคัดลอกตารางเป็นภาษาอังกฤษ และ {{app.tools.portscan.export}} จะเขียนแถวลงไฟล์ CSV

พอร์ตเดียวจากคอนโซล

ถ้าจะตรวจพอร์ต TCP เพียงพอร์ตเดียว PowerShell และระบบ Linux ส่วนใหญ่มีสิ่งที่ต้องใช้อยู่แล้ว

Test-NetConnection example.com -Port 443
nc -zv example.com 443

หากต้องการรู้เวอร์ชันของบริการหรือระบบที่ปลายอีกด้าน ให้ใช้ nmap ส่วนเครื่องมือนี้ตอบคำถามที่มาก่อนหน้านั้น คือพอร์ตไหนตอบกลับบ้าง ทั้งผ่าน TCP และ UDP โดยไม่ต้องติดตั้งอะไรเพิ่ม
